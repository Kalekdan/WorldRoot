# WorldRoot
A tool to generate worlds from the high level planets, continents, down to individual people in the world. Generates all as you click through


## Structure of a world
World Root generates worlds in a nested structure, with each individual element being a separate child component. The following is a loose structure with more elements to be added.

- World
  - Continents
     - Settlements
        - Buildings
            - People
     - Points of interest
  - Seas
